# Course Brief

## Course title
JavaScript Promises 101

## Target learner
A junior developer who knows basic JavaScript (variables, functions, arrays) but
has never worked with asynchronous code.

## Level
Beginner

## Language
English only. All generated course content (titles, units, knowledge, questions,
hints, answers, common mistakes, TeacherBrain) will be in English. Multilingual
generation is not supported yet.

## Course goal
By the end of the course, the learner should be able to read and write basic
Promise-based code: create a Promise, consume one with `.then`/`.catch`, and
explain why async matters.

## Teaching style
Practical, short, guided, Socratic when useful, not too theoretical.

## Runtime assumption
The final course will be taught by a weak tutor model.

The weak model receives only:
- current unit
- TeacherBrain
- 2–3 relevant KB chunks
- questions / hints / expected answers
- short progress snapshot

Therefore the CoursePackage must contain the teaching intelligence in advance.

## Desired unit length
Each final unit should be about 10 minutes.

If the input units are too broad, split them.
If the input units are too small, merge them if appropriate.

## Must include
- Why async code exists (the blocking problem).
- What a Promise is and its three states.
- Consuming a Promise with `.then` and `.catch`.

## Avoid
- async/await (that belongs in a later course).
- Node.js-specific APIs.

## Notes
Keep examples framework-free — plain browser/JS only.
